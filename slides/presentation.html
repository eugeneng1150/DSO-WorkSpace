Progress Update — 9 June 2026

Multi-Agent Marketplace Simulation

Comparing 9 institutional cooperation mechanisms for self-interested LLM agents under progressive adversarial stress.

“

Can institutional mechanisms help self-interested LLM agents sustain cooperation under escalating adversarial pressure?

Which mechanism designs are robust to progressive troll injection?
Do enforcement-based, insurance-based, or information-based mechanisms degrade differently?
At what adversarial density does each mechanism break?

Background

Literature Context

  • Without mechanisms, all modern LLMs defect in social dilemmas (CoopEval)
  • Contracting & Mediation ranked most effective in controlled experiments (CoopEval)
  • More capable reasoning LLMs become better free-riders, not more cooperative (Corrupted by Reasoning)
  • Reputation + dynamic networks + gossip yields 85–98% cooperation (RepuNet)
  • Prompt-level governance (“be honest”) is indistinguishable from no governance (Institutional AI)
  • A single defector can collapse the system in 1–7 rounds (Subtle Art of Defection)

Gap: Most studies test one mechanism in isolation — we compare 9 head-to-head under progressive adversarial stress using a single model.

Setup

The Environment

  • 18 LLM agents (DeepSeek-V3) in a marketplace over 200 rounds
  • Each round: produce goods, communicate, trade, consume
  • Agents need diverse goods to earn utility — incentivizes trade
  • 20% spoilage per round — hoarding is penalized
  • Adversarial stress test: progressive troll injection — 0→4→8→16 trolls injected at rounds 51, 101, 151
  • Trolls appear silently — agents discover them only through experience

Conditions

The 9 Conditions

  • B Baseline — no mechanism, pure barter
  • GR Global Reputation — system-computed trust scores visible to all
  • C Contracting — binding agreements with breach penalties
  • M Mediation — agent-designed mediator, bilateral delegation
  • G Governance — omniscient oracle detects and punishes defectors
  • NR Network Rewiring + Local Reputation — gossip + link severing
  • S Sanctioning — collective punishment for defectors
  • J Judicial — complaint-driven court with imperfect information (new)
  • E Escrow — shared insurance pool, mutually assured destruction (new)
New Mechanism

Judicial (J) — Complaint-Driven Court

Unlike Governance (G), where an omniscient oracle auto-detects defectors, Judicial requires the victim to act — introducing imperfect information and strategic cost.

→
Files complaint
−1 utility filing fee
→
Court verifies
via trade history
→
Verdict

Guilty Verdict

  • Defector fined −5 utility
  • Victim compensated +3 utility
  • Net for victim: +2 (after filing fee)

Dismissed (False Claim)

  • Filer pays additional −2 utility
  • Total cost: −3 for a false complaint
  • Deters frivolous litigation

Key design: G has perfect information (oracle sees all). J has imperfect information — the court only examines what the victim reports. Filing is a strategic choice: is the expected payout worth the risk?

New Mechanism

Escrow (E) — Shared Insurance Pool

A collective insurance pool that automatically compensates defection victims — but collapses catastrophically when depleted.

How It Works

  • Shared pool starts at 100 utility
  • Each defection: victim automatically receives +4 from the pool
  • Pool never replenishes
  • No agent action required — fully automatic

The Collapse

  • When the pool reaches 0:
  • ALL agents’ total utility resets to 0
  • Mutually assured destruction
  • Agents know the pool balance each round

Tragedy of the commons: Every defection drains the shared pool. With 100 starting balance and 4 per payout, the pool survives only ~25 defections. Progressive troll injection (up to 16 trolls) will test how fast the pool collapses — and whether agents adapt their behavior to prevent it.

Stress Test

Progressive Troll Injection

Instead of a fixed troll count, trolls are injected mid-game in waves. Cooperation must establish first, then survive escalating adversarial pressure.

  • Phase 1 (rounds 1–50): Pure cooperation — agents build trust and trading patterns
  • Phase 2 (rounds 51–100): Mild pressure — 4 trolls appear silently, 18% adversarial
  • Phase 3 (rounds 101–150): Moderate pressure — 8 trolls total, 31% adversarial
  • Phase 4 (rounds 151–200): Severe pressure — 16 trolls, nearly half the population

Key question: Does established cooperation (50 rounds of trust) provide resilience that cold-start trolling does not? Which mechanisms degrade gracefully vs collapse suddenly?

Measurement

How We Measure Success

Mean Utility per Round

  • Average utility across non-troll agents each round
  • Production cost (−1) vs consumption gain (+3)
  • Agents need trade to be net positive
  • The bottom line — are agents better off?

Gini Coefficient

  • Inequality of utility distribution
  • 0 = perfectly equal, 1 = one agent takes all
  • A mechanism that helps 3 agents while starving 15 is not a good mechanism
  • Fairness check — does the mechanism help everyone?

All metrics exclude troll agents — we measure how well the self-interested agents fare, not the trolls. We deliberately focus on two core metrics to keep analysis clean and avoid correlated-metric redundancy.

Parameters

Experiment Setup

  • Model: DeepSeek-V3 (via Azure) — $0.58 / $1.68 per 1M input/output tokens
  • Troll injection: Progressive — 0→4→8→16 trolls at rounds 51 / 101 / 151
  • Duration: 200 rounds per run, 1 run per condition
  • Conditions: 9 — B, GR, C, M, G, NR, S, J, E
  • Metrics: Mean utility per round, Gini coefficient
  • Agents: 18 self-interested (start) → up to 34 total (18 + 16 trolls)

Why single-model? Previous multi-model runs showed that model capability dwarfs mechanism effects. We fix the model (DeepSeek-V3) to isolate mechanism differences, and use progressive injection for richer stress dynamics than fixed troll counts.

Design Space

The Mechanism Spectrum

Our 9 conditions span three axes of institutional design:

Information

  • B — none
  • GR — global, perfect
  • NR — local, imperfect (gossip)

Enforcement

  • C — pre-trade penalties
  • G — omniscient oracle
  • J — complaint-driven court
  • S — collective punishment

Insurance

  • M — third-party mediation
  • E — shared pool (depletable)

J vs G tests whether enforcement needs perfect information. E tests whether collective insurance creates a tragedy of the commons under adversarial pressure.

Prior Results

Key Findings from Initial Runs

From earlier multi-model experiments (nano, mini, DeepSeek) with fixed troll counts (0/2/4 trolls, 30 rounds):

  • Model capability > mechanism choice — baseline utility spread across models (1.42–5.35) dwarfed any mechanism effect
  • Governance (G) was the only mechanism never net-negative across all 3 models — but it has perfect information (oracle)
  • Contracting (C) consistently harmful — penalty fear froze trade volume. Prompt updated to remove fear-inducing language
  • NR and GR were capability-gated — worked for DeepSeek, failed for weaker models that couldn’t reason about reputation signals
  • Mediation (M) had a delegation bug — only acceptors could delegate, not proposers. Now fixed with bilateral delegation

These findings motivated the current design: fix the model (DeepSeek), add J (imperfect enforcement) and E (collective insurance), and test with progressive stress instead of static troll counts.

Hypotheses

What We Expect to See

G should dominate early

Omniscient oracle catches trolls immediately. But does perfect enforcement create dependency? What happens when 47% of agents are trolls and fines pile up?

J tests imperfect enforcement

Filing costs create a threshold — agents must decide if it’s worth complaining. Expect slower troll isolation than G, but potentially more resilient long-term behavior.

E should collapse in Phase 4

100-point pool / 4 per defection = ~25 defections to collapse. With 16 trolls defecting every round, the pool drains in 1–2 rounds after Phase 4 injection. Does the threat of collapse change agent behavior before it happens?

Progressive ≠ Static

50 rounds of established cooperation should provide resilience that cold-start trolling does not. Mechanisms that rely on learned behavior (NR, GR) may degrade more gracefully than structural ones (C).
